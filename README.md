Sistema de gerenciamento de produtos desenvolvido em linguagem C como projeto acadêmico, com foco na aplicação de conceitos de programação e manipulação de dados.

Funcionalidades :

Cadastro de produtos com informações detalhadas.

Consulta e listagem de produtos cadastrados.

Edição de informações existentes.

Exclusão de produtos.

Armazenamento persistente dos dados em arquivo de texto.
